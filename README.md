## איך מתקינים סקיל

קודם קוראות אותו: לוחצות על השם בטבלה וקוראות את הקובץ. סקיל הוא הוראות שהבינה מבצעת, ולכן לא מתקינים סקיל בלי לקרוא אותו.

**ב־Claude** אפשר להתקין ישר מכאן: Plugins → Add → Add marketplace → Add from a repository. כותבות `ruthprissman/skills`, לוחצות Sync, ואז Add ליד הסקיל.

**ב־ChatGPT ובג׳מיני** מורידות את קובץ ה־ZIP מהטבלה, ומעלות אותו כמו שהוא:

- **ChatGPT:** Plugins → Skills → Add → Upload from your computer. את הסקיל מפעילים במצב Work, עם @.
- **ג׳מיני:** הגדרות ← סקילים ← יצירה ← העלאה, ואחר כך ״יצירה״. את הסקיל מפעילים עם @.

אותו ZIP עובד גם ב־Claude: Plugins → Add → Upload plugin.
