## איך מתקינים סקיל

לפני שמתקינות, בודקות. לא צריך לקרוא את כל הסקיל: מצרפות את קובץ ה־ZIP לשיחה רגילה, וכותבות:

> תבדוק את הסקיל המצורף מבחינת אבטחה, ותסביר לי בשני משפטים מה הוא עושה.

**ב־Claude** אפשר להתקין ישר מכאן: Plugins → Add → Add marketplace → Add from a repository. כותבות `ruthprissman/skills`, לוחצות Sync, ואז Add ליד הסקיל.

**ב־ChatGPT ובג׳מיני** מורידות את קובץ ה־ZIP מהטבלה, ומעלות אותו כמו שהוא:

- **ב־ChatGPT:**‏ Plugins → Skills → Add → Upload from your computer. את הסקיל מפעילים במצב Work, ולא במצב Chat.
- **בג׳מיני:** הגדרות ← סקילים ← יצירה ← העלאה, ואחר כך ״יצירה״.

את אותו ZIP אפשר להעלות גם ל־Claude, דרך Plugins → Add → Upload plugin.

ב־ChatGPT בדקתי בחשבון Pro. בחשבון חינמי של ChatGPT אין סקילים. בג׳מיני הסקיל עובד גם בחשבון חינמי.
